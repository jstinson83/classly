# Classly

School organization app: photograph your schedule and agenda, get a
calendar of classes, assignments, and study time, add reminders and notes,
and plan with an AI chat assistant.

Status: scaffold — a home page with a "Hello Gemini" button.

Run locally: `cd backend && GEMINI_API_KEY=... ./gradlew run`, then open
http://localhost:8080. Tests: `./gradlew test`.

See `.claude/context.md` for the overview and `.claude/current.md` for the plan.
